# Crest iOS → Android 迁移状态

更新时间：2026-09-30

本文以现有 iOS 代码的业务行为为基准。状态说明：`已完成` 表示 Android 已接入真实接口并具备主要状态处理；`部分完成` 表示主链路可用，但仍缺少 iOS 中的细节或子功能；`待迁移` 表示尚未在 Android 实现。

## 功能对照

| 功能域 | iOS 现有能力 | Android 当前状态 | 主要差异 |
| --- | --- | --- | --- |
| 登录注册 | 手机号识别、密码/验证码登录、个人注册、重置密码、验证码倒计时 | 已完成 | 仍需真机覆盖弱网、短信自动填充等体验 |
| 登录状态 | Access Token、Refresh Token、过期刷新、登录失效处理 | 已完成 | Android 使用系统密钥库加密保存 Refresh Token |
| 工作空间 | 工作空间列表、切换、退出、邀请码加入团队 | 已完成 | 需补更多异常场景验证 |
| 个人资料 | 昵称、密码、头像 | 部分完成 | 昵称和密码已完成；头像选择、裁剪、上传待迁移 |
| 对话主流程 | 新建、历史记录、流式回复、停止、审批、澄清 | 已完成 | 已使用真实接口；需继续做复杂回复回归 |
| 对话管理 | 搜索、置顶、重命名、删除确认 | 已完成 | 搜索当前基于已加载的会话标题 |
| 消息操作 | 复制、分享、重新提问 | 已完成 | “重新提问”沿用 iOS 行为：重新发送上一条用户问题 |
| 消息呈现 | Markdown、结构化卡片、逐字播放 | 部分完成 | 结构化摘要/指标/提示/表格已具备；Markdown 与逐字播放待迁移 |
| 经营概览 | 昨日/近 7 天/本月/上月、核心指标、渠道表现 | 已完成第一阶段 | 已接入真实概览接口；门店筛选和趋势待补 |
| 经营分析子模块 | 订单、商品、人效、预警、详情、导出、缓存 | 待迁移 | 按接口和 iOS 页面逐模块补齐 |
| 系统能力 | 图片选择、权限、深链接、推送 | 待核对/待迁移 | 只在用户触发功能时申请权限 |
| 视觉与无障碍 | iOS 品牌样式、动态字体、深浅色 | 部分完成 | Android 已有主题与基础品牌资源；需逐页视觉验收 |

## 本轮已完成

1. 账户与团队
   - 读取并修改昵称。
   - 首次设置密码、修改密码；个人账户缺少密码时自动提醒。
   - 使用邀请码加入团队，并刷新工作空间列表。

2. 对话体验
   - 对话重命名、删除前确认。
   - 助手消息复制、系统分享、失败后重新提问。

3. 经营分析第一阶段
   - 以 Asia/Shanghai 时区生成与 iOS 一致的日期范围。
   - 展示净实收、订单数、客单价和渠道表现。
   - 覆盖加载中、空数据、请求错误、刷新状态。

## 后续实施顺序

### 第二阶段：经营看板完善

- 门店筛选。
- 营收/订单趋势。
- 订单分析及明细入口。

验收：筛选条件与 iOS 一致；切换周期/门店后请求参数正确；空数据、错误和登录失效可恢复。

### 第三阶段：经营分析全模块

- 商品分析、人效分析、经营预警。
- 明细页面、CSV 导出和本地缓存策略。

验收：主要指标口径、排序、筛选和导出内容与 iOS/后端定义一致。

### 第四阶段：资料与消息体验

- 头像选择、裁剪和上传。
- Markdown、复杂结构化回复和逐字播放。
- 对话搜索范围与长历史加载优化。

验收：图片权限按需申请；上传失败可重试；同一回复在双端关键信息一致。

### 第五阶段：平台能力与发布前验收

- 核对深链接、推送和系统权限。
- 多尺寸、深浅色、动态字体、无障碍和弱网回归。
- Release 构建、签名、隐私清单和应用市场材料检查。

验收：核心流程真机通过；无敏感日志；Release 包可安装且无阻断级崩溃。

## 当前限制

- 自动化构建和本地模型解析测试不依赖账号；真实业务数据、短信、团队邀请和经营指标仍需使用可用测试账号做端到端验收。
- iOS 工程保持只读，本轮未修改任何 iOS 源代码。
